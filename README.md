# Карточный клуб

Мобильное PWA-приложение на HTML/CSS/JavaScript. Включает три режима:
- **Дурак** — подкидной, 2–4 бота, три уровня сложности.
- **Косынка** — классический пасьянс, семь столбцов, открытие по одной карте, отмена хода.
- **Свободная ячейка** — 52 карты, четыре временные ячейки, восемь столбцов, автосбор и отмена.

## Запуск
Для локальной проверки откройте `index.html` в современном браузере. Для установки PWA нужен HTTPS-хостинг или `localhost`:
1. Разместите все файлы каталога на HTTPS-хостинге (например, GitHub Pages).
2. Откройте адрес на телефоне.
3. Android/Chrome: меню браузера → «Установить приложение» или «Добавить на главный экран».
4. iPhone/Safari: «Поделиться» → «На экран Домой».

Service worker кеширует приложение для автономного запуска после первой загрузки.

## Структура
- `index.html` — экраны, диалоги обучения и игровая область.
- `styles.css` — адаптивный дизайн, карточный стол и компоненты интерфейса.
- `app.js` — игровая логика, боты, правила, обучение и взаимодействия.
- `manifest.webmanifest` — параметры PWA.
- `sw.js` — офлайн-кеш.
- `icon.svg` — иконка.

## Управление
В пасьянсах: нажмите карту, затем целевую стопку/ячейку. В Дураке: выберите карту и нажмите действие. Кнопка «Подсказка» объясняет возможный следующий ход.

## Примечания
Это устанавливаемое веб-приложение (PWA), а не подписанный APK/IPA. Для публикации в Google Play потребуется обёртка (например, Capacitor), Android SDK и подпись сборки; для App Store — отдельная нативная сборка и соответствующая учётная запись.
